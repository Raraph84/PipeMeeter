# PipeMeeter

An audio mixer for PipeWire, inspired by VoiceMeeter, built with Electron and React.

<img width="1549" height="1051" alt="image" src="https://github.com/user-attachments/assets/2faedb42-939d-4308-bf26-bc87bd2c2482" />

## Features

- Manage physical and virtual audio inputs and outputs
- Per-node volume and mute control
- Create and remove links between inputs and outputs
- System tray icon

## Requirements

- Node.js
- PipeWire

## Installation

```bash
npm install
npm install --prefix renderer
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Run the app

```bash
npm start
```

## Package

```bash
npm run package
```
